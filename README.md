# Laravel Museum CMS

A Laravel-based museum CMS practice project inspired by modern digital infrastructure used by museums and cultural institutions.

This project was built as hands-on preparation for Laravel CMS, API, and digital asset management workflows.

---

## Features

- Public exhibition pages
- Admin dashboard
- Exhibition CRUD functionality
- JSON API endpoints
- Blade templating
- Tailwind CSS UI
- Laravel MVC architecture
- Eloquent ORM integration
- Responsive layouts
- Vite frontend asset pipeline

---

## Tech Stack

- PHP
- Laravel
- Blade
- Tailwind CSS
- Vite
- SQLite
- Git / GitHub

---

## Current Functionality

### Public Pages
- `/exhibitions`
- `/exhibitions/{slug}`

### Admin CMS
- `/admin/exhibitions`
- Create exhibitions
- Edit exhibitions
- Publish/unpublish workflow

### API
- `/api/exhibitions`

Returns JSON data for API/mobile app integration.

## Local Development

Install dependencies:

```bash
composer install
npm install
```

Run Laravel:

```bash
php artisan serve
```

Run Vite:

```bash
npm run dev
```
